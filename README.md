# The Captain Gym Website

## Project Overview

The Captain Gym is a modern business website designed for a local fitness center in Ramachandrapuram, Andhra Pradesh.

This website helps the gym establish a professional online presence, showcase its services, provide membership information, and allow potential customers to contact the gym easily.

## Features

* Responsive design for mobile and desktop
* Modern fitness-themed user interface
* About section
* Services section
* Membership plans
* Trainer profiles
* BMI Calculator
* Gallery section
* Testimonials
* FAQ section
* Contact form
* WhatsApp integration
* Google Maps location integration

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Netlify (Deployment)
* GitHub (Version Control)

## Business Problem Solved

Many local gyms rely only on word-of-mouth marketing and social media. This website provides:

* Better online visibility
* Easy access to contact information
* Professional branding
* Improved customer trust
* Faster communication through WhatsApp
